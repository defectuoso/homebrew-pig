# Defectuoso Pig

## How do I install these formulae?

`brew install defectuoso/pig/<formula>`

Or `brew tap defectuoso/pig` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "defectuoso/pig"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
